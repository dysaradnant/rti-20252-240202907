# Kontribusi Penelitian

Penelitian ini memberikan beberapa kontribusi ilmiah, yaitu:

1. Mengembangkan model **Adaptive Energy Scheduler** berbasis skor komposit yang mengintegrasikan kondisi baterai, produksi energi panel surya, kebutuhan beban, dan temperatur lingkungan.

2. Melakukan evaluasi menggunakan dataset **NASA POWER** dengan resolusi per jam selama satu tahun penuh (8.784 data), sehingga hasil penelitian lebih representatif dibandingkan pengujian jangka pendek.

3. Membandingkan performa Adaptive Energy Scheduler dengan Rule-Based Scheduler melalui **Multiple Run Experiment** sebanyak lima kali.

4. Melakukan analisis statistik menggunakan statistik deskriptif, **Paired t-test**, **Independent t-test**, dan **Cohen's d** untuk mendukung validitas hasil penelitian.
